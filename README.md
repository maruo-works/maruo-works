## まるお

業務を理解したうえで、AI を使って開発・修正・対応します。

- 業務効率化ツール（Excel・CSV・PDF の自動処理、業務システムへの自動入力）
- 記事の下書きの自動作成（Python・WordPress）
- Web サイト制作（Astro）

### 公開している作品

| 作品 | 内容 |
|---|---|
| [feed2wp-draft](https://github.com/maruo-works/feed2wp-draft) | 新着フィード（YouTube・note など）から記事の下書きを作り、WordPress に下書き保存するツール |
| [xlsx-month-roll](https://github.com/maruo-works/xlsx-month-roll) | Excel の月の表記と日付を、書式を崩さずに次の月へ進めるコマンド |
| [maruo-works.com](https://github.com/maruo-works/maruo-works.github.io) | 個人サイト・ブログ（Astro） |

仕事で作ったものは、取引先の情報を含むため公開していません。

### 進め方

1. 作る前に、目的・入力・出力・確かめ方を設計書にまとめる
2. 実装は AI に任せ、動作確認と修正は自分で行う
3. 公開の前に、個人情報や取引先の情報が入っていないかを確かめる
